# Head Rush: The Human Body in Space — play online

**Play: https://tjfreeborn1.github.io/head-rush-play/**

This repository only hosts the packaged game so it can be played in a browser with nothing to download. Click the link, wait for the loading bar (about 37 MB on the first visit), click the green flag, pick G4 or G7, and start Mission 1.

- `index.html` is Head Rush **2.0.1** (SHA-256 `b9c7a58d2adc2ca80175b14e19b23d2fd38140e61da868e5834e2bf5ba2a3694`), the same file as the 2.0.1 download.
- The version is shown on the title screen beside the round **i** button.
- Prefer to play offline, or on unreliable school wifi? Save the page, or download `index.html` and double-click it; it runs with no internet.
